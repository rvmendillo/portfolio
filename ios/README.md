# Rey Portfolio OS for iPhone

The repository's **Build iPhone IPA** workflow compiles this SwiftUI/WKWebView wrapper on a GitHub-hosted macOS runner.

Download the `ReyPortfolioOS-unsigned-ipa` workflow artifact, extract `ReyPortfolioOS-unsigned.ipa`, then import it into Feather. Feather must have the certificate's matching private key and a provisioning profile that permits `com.reyvictor.portfolioos` and the target iPhone.
